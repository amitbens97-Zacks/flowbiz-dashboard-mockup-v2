# מוק-אפ: דף הבית של FlowBiz עם המסע החדש (נובמבר 2026)

עותק חדש של המוק-אפ הקודם (flowbiz-dashboard-mockup נשאר כמו שהוא), עם מפת הדרכים לפי המסע החדש: 6 פרקים, 15 שלבים, דרגה בסוף כל פרק, כרטיס "הלידים שלי", מסך תשלום אחרי שלב 5 ו-FlowBiz Plus בקרוב בסוף המסע.

מוק-אפ של **ממשק בלבד** לדאשבורד הראשי (מפת המסע), באותה שפה עיצובית של מוק-אפ שלב אפיון המוצר (v3): מחברת, עיפרון צבעוני, מרקר וכתב יד.

- **אין צד שרת:** הנתונים מדומים (`src/data.js`).
- **הערות למפתחים:** כפתור **"הערות למפתחים"** בסרגל העליון (או Shift+D) מסביר מה נשאר, מה הוסר ולמה, ומאפשר לעבור בין שלבים במסע: משתמש חדש, באמצע, כמעט בסוף, וסיים.

## הרצה

אתר סטטי בלי build. צריך רק שרת קבצים:

```bash
python -m http.server 4184
```

ואז לפתוח את http://localhost:4184. ב-Windows אפשר גם ללחוץ פעמיים על `open-mockup.bat`.

## מה בדאשבורד

| חלק | תוכן |
|---|---|
| חלונית המפה (בראש העמוד) | ברכה, "המסע שלך להקמת העסק", התקדמות אחת (שלבים מתוך 15, או 14 למי שדילג על "מציאת רעיון"), "חסכת עד עכשיו" וכרטיס "הצעד הבא שלך" עם כפתור "המשך מכאן" |
| מפת המסע | 6 פרקים על דרך מאוירת עם פניות מעוגלות, שעולה בהדרגה עד קו הסיום בפינה השמאלית העליונה: הושלם (וי), נוכחי ("אתה כאן"), נעול. לחיצה על פרק פותחת את הצעדים שלו בחלונית מרחפת |
| משימות להיום | 3 משימות לפי הצעד הנוכחי, עם וי בעיפרון |
| הלידים שלי | נפתח בשלב 11 עם "סגרתי!" לכל ליד. "לידים" בתפריט נעול עד שלב 14 |
| הדרגה שלך | הדרגה הנוכחית והבאה, ולחיצה פותחת את כל הדרגות (זכר/נקבה לפי "איך נפנה אליך?") |
| הכריש | סגור, עם סימון "הודעה חדשה". רק לחיצה פותחת אותו |

**מה הוסר:** "רמת מייסד", "אנרגיה", "התקדמות כללית" הכפולה, "מסע היזמות 19/20 משימות" ואייקון המגן.

## מבנה הקבצים

```
index.html          טוקני מותג, גופנים, רקע מחברת, מרקמי עיפרון
src/main.js         הדאשבורד: סרגל עליון וניווט, חלונית המפה (כותרת, התקדמות, הצעד הבא), משימות, לידים, שותף
src/journeymap.js   מפת המסע: הדרך המאוירת, חלונית מרחפת לצעדי הפרק (פריסה רוחבית למחשב ואנכית למובייל)
src/data.js         פרקים וצעדים, תרחישים, משימות, לידים, השותף
src/devnotes.js     פאנל "הערות למפתחים"
src/components.js   רכיבים משותפים (מ-v3)
src/lib.js          אייקוני עיפרון, וי מונפש, עזרים (מ-v3)
src/viewswitch.js   מתג מחשב/מובייל ומסגרת טלפון (מ-v3)
assets/             הלוגו של FlowBiz
```

## מובייל

האתר מותאם לגמרי למובייל:
- הניווט עובר לסרגל תחתון.
- המפה הופכת לדרך אנכית.
- צעדי הפרק נפתחים בחלון תחתון.

בסרגל העליון יש מתג "מחשב / מובייל", כמו במוק-אפ v3.
